# Python AI Projects
A collection of Python-based AI applications that leverage Large Language Models (LLMs) to solve real-world tasks through 
intuitive command-line interfaces. 
This repository showcases practical AI development using modern Python tooling, API integration, prompt engineering, 
and modular software design. 
Each project focuses on a unique use case while demonstrating clean architecture, maintainable code, and real-world AI 
workflows.

---

## 📂 Projects:--------------------------

### 1. 🤖 AI Chatbot
A conversational AI assistant that uses Large Language Models (LLMs) to generate intelligent, context-aware responses 
through an interactive command-line interface.

**Highlights**
- Natural language conversations
- LLM-powered responses
- Secure API key management
- Interactive CLI experience

---

### 2. 📄 AI Resume Critiquer
An intelligent resume analysis tool that reviews resumes, provides personalized feedback, and suggests actionable 
improvements to enhance resume quality.

**Highlights**
- Resume evaluation
- AI-generated feedback
- Improvement suggestions
- Easy-to-use CLI interface

---

### 3. 🖼️ AI Image Classifier
An AI-powered image analysis application that leverages multimodal LLM capabilities to identify, analyze, and describe 
image content.

**Highlights**
- Image understanding using AI
- Detailed image descriptions
- Fast inference with Groq API
- Simple command-line workflow

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Rachita-R/python_ai_projects.git
cd python_ai_projects
```

### Navigate to any project

```bash
cd ai_chatbot
```

or

```bash
cd ai_image_classifier
```

or

```bash
cd ai_resume_critiquer
```

### Install dependencies

```bash
uv sync
```

### Configure environment variables

Create a `.env` file inside the project directory and add:

```env
GROQ_API_KEY=your_api_key_here
```

### Run the application

```bash
uv run main.py
```
