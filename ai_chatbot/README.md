**Description:**
* An intelligent AI chatbot developed using Python, LangChain, LangGraph, and the Groq API. 
* The chatbot understands natural language queries, generates context-aware responses using large language models (LLMs), and supports tool calling to perform specific tasks such as mathematical calculations. 
* Built with a modular architecture, the project demonstrates how modern AI agents can combine reasoning with external tools to solve user queries effectively.

**Features:**
Natural language conversations
LLM-powered responses using Groq
Tool calling with LangChain
Function execution (calculator, greeting tools, etc.)
Agent-based reasoning using LangGraph
Interactive command-line interface (CLI)

**Tech Stack:**
Language: Python
LLM: Llama 3.1 8B Instant (Groq)
Frameworks: LangChain, LangGraph
API: Groq API
Environment: Python Dotenv
Development Tool: UV Package Manager
